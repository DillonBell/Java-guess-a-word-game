# Java-guess-a-word-game

## Objective

I wanted to create a game with what I learned in Java

### Skills Learned

- Using Control Structures, like do-while loops and switch statements.
- Array and String Manipulation (Character Arrays, Filling Arrays, Comparing Arrays, String Conversion).
- Utilizing Random to select a word randomly from the chosen category.
- Error Handling and Input Validation. In the code I made sure that the input gets converted to lowercase and trimmed, also made it take only the first character of the user input.
- Boolean Logic.

### Real-World Applications
- Skills here can be extended to create more complex games like hangman.
- Techniques like trimming and normalizing input are crucial in real-world software.

### Tools Used

- Intellij IDEA
